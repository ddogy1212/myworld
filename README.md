# MYWORLD 1.2 · 세계 문명 전략 시뮬레이션 🌍🎮

**실제 국경을 누르고, 국가를 성장시키고, 정책의 결과를 바로 확인하는 오프라인 문명 시뮬레이션.**

현실 24시간 = 게임 1개월. **197개 국가·정치 실체**가 연구·경제·외교·사회 정책을 스스로 결정하며, 플레이어는 직접 정책과 외교를 명령할 수 있습니다.

## 1.2 달라진 점
- 🌐 실제 Natural Earth 국경 지도 (165개 국가 다각형 + 32개 확대 시 소국 마커)
- ✋ 화면을 드래그하고 확대해 나라를 누르면 국가 운영 화면으로 이동
- ⚡ 정책 실행 뒤 실제 게임 수치 **변경 전 → 변경 후** 결과 창
- 🎯 첫 플레이 안내, 5개 임무와 달성 보상
- 📈 세계 경제·평화·환경의 지난 12개월 흐름 그래프
- ⌨️ 직접 한국어 문장으로 명령을 입력하고 검토 후 시행
- 🌍 1×1 및 2×2 위젯 두 종류 (큰 위젯에 최근 정책 결과 반영)
- 🗺️ 작은 나라까지 검색 가능한 197개 세계 국가·정치 실체

## 다운로드

GitHub Actions를 통해 자동 컴파일된 APK: [downloads/myworld-debug.apk](downloads/myworld-debug.apk) (빌드 완료 후 이용 가능). 사용 방법과 게임 규칙은 [GAMEPLAY.md](GAMEPLAY.md), 국가 통계 출처와 정확도는 [DATA_SOURCES.md](DATA_SOURCES.md).

## 제약

국경 데이터는 1:110m 축척이므로 작은 섬·영토·분쟁 지역 표기에 한계가 있습니다. **현재 국제 정세의 국가별 분쟁·동맹·국가정책을 완벽하게 복제한 게임이 아니며**, 국가의 사회·경제 지수와 진행 결과는 가상의 대체역사 모델입니다. 개발 중인 독립형 Android 게임으로 실기기 확인이 필요합니다.
