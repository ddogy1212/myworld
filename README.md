# MYWORLD 🌍

오프라인에서 계속 변화하는 가상 지구 문명 시뮬레이션. **현실 24시간 = 게임 1개월**. 국가들은 자동으로 경제, 연구, 사회, 외교, 무역, 기후 정책과 국제 분쟁을 변화시킵니다. 플레이어는 개입 포인트로 국가 정책과 국제협력을 결정합니다.

자동 진행은 기기 저장 시간으로 계산하고 Android 백그라운드 작업이 갱신을 시도하며 앱/위젯을 열 때 놓친 달을 정확히 따라잡습니다. Android 절전 정책 때문에 백그라운드 실행 시각은 보장되지 않습니다.

*모든 국가 능력치·사건은 게임용 가상 수치이며 실제 현재 국제정세나 미래를 예측하지 않습니다.*
