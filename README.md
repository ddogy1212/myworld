# MYWORLD 🌍

**앱을 열지 않아도 변하는 가상 지구**. 현실 24시간마다 게임 1개월이 흐르며, 24개 가상화된 국가가 저마다 정책·기술·무역·외교·사회 변화를 결정합니다. 앱에서는 원하는 국가와 외교 관계에 직접 개입할 수 있습니다.

## 설치 및 위젯

1. GitHub Actions가 성공적으로 APK를 빌드하면 [설치용 APK](downloads/myworld-debug.apk)를 받을 수 있습니다.
2. MYWORLD 앱 실행 후 가상 세계가 생성되는 것을 확인합니다.
3. 휴대폰 홈 화면을 길게 눌러 **위젯 → MYWORLD**로 이동합니다.
4. **1×1**과 **2×2** 중 원하는 위젯(또는 두 개 모두)을 배치합니다. 두 위젯은 같은 세계를 표시합니다.
5. 작은 위젯에는 미니 지구·게임 날짜·경제·평화, 큰 위젯에는 지구·날짜·경제·평화·기후·인구·최근 월간 뉴스가 표시됩니다.

## 플레이
- **세계**: 지구 지도에서 국가 선택, 월간 시간, 평화·경제·기후·연구 현황, 주요 사건 확인.
- **국가**: 24개 나라, 사회집단 만족도 5개, 연구분야 5개, 경제·정치·보건·교육 등 개별 국가 지표 및 8개 정책 개입.
- **외교**: 두 나라를 선택하고 관계·무역·긴장도를 확인하며 무역협정·대화·연구교류·기후협력·중재를 시행.
- **역사**: 매월 기록되는 사건, 발전, 협정, 분쟁, 정책과 연간 보고서.
- **정보**: 세계 시계, 자동 진행 원리, 초기화.

**게임은 100% 오프라인**, Android가 백그라운드 업데이트를 지연시켜도 앱/위젯 사용 시 현실 경과 시간에 맞춰 지나간 달을 따라잡습니다. 단, 위젯 표시 갱신 시각 자체는 Android 절전 정책에 따라 늦어질 수 있습니다.

상세 지표·규칙·자동화 방식과 한계는 [DESIGN.md](DESIGN.md)에 설명했습니다. 국가의 모든 수치와 사건은 게임용 가상 설정이며 현실에 대한 예측이 아닙니다.

## 197개국 확장 빌드 검증
UN 회원국 193 + 옵서버 2 + 별도 표기 2, 세계은행 인구·GDP 연도 구분, 텍스트 명령 입력 및 24개월 장기 정책 엔진을 테스트합니다.
